## Как читать

На этой машине кадры укладываются с запасом, поэтому FPS сам по себе ничего не доказывает. Опорный показатель для слабых устройств это **число изменений DOM в секунду**: каждые 100 мс (`tick`) перерисовывается весь экран игры, а астронавты ещё двигаются через прямые правки атрибутов SVG. Цель рефакторинга (шаг A3) снизить это число в разы, не меняя вида. Сравнивать нужно в тех же условиях.
