## Что должно получиться

Игра полностью играбельна и красива на: 390×844, 430×932 (портрет), 844×390, 932×430, 667×375 (ландшафт), 820×1180, 1180×820 (планшет), а также на ноутбуке 1024×768 и десктопе 1280×800.

- Нет перекрытий: плашка базы, ресурсы, панель экипажа, цель, карточки заданий, кнопка «Будівництво», зум не лежат друг на друге ни на одной стадии (меню, пролог, правила, миссия, меню строительства, выбор места, событие, итоги дня, финал, «Данные NASA»).
- Все кнопки не меньше 44×44 px, текст не меньше 12 px, ничего не вылезает за экран.
- iPhone: `viewport-fit=cover` уже включён, отступы под вырез в `src/styles/safe-area.css`. Проверь, что по бокам нет пустых полос и панели не уходят под вырез.
- Касание: нет зависимости от hover (подсказка модуля открывается тапом или осознанно скрыта), список модулей на низком экране прокручивается свайпом, клик по карте не срабатывает при перетаскивании.
- Портретный телефон сейчас показывает «Поверни пристрій» (`rotate-hint`). Реши и опиши в PR, можно ли играть в портрете; включать только если всё помещается.
- Шрифты и иконки в плашках ресурсов читаются, подсказки не уезжают за край экрана.

## Правила

- Меняй `src/styles/*.css`, `src/features/**/*.css` и разметку `src/features/**/*.tsx`. Не трогай `src/engine`, `server`, `shared`, баланс, тексты правил. Движок детерминирован: никакого `Math.random` и `Date.now` внутри `src/engine`.
- Тесты для UI: `e2e/viewports.spec.ts` (функция `checkLayout` ищет выход за экран, перекрытия и накрытые кнопки). Расширяй её, но не отключай проверки через `fixme`.
- Перед каждым коммитом зелёное: `npm run lint`, `npm run typecheck`, `npm run check`, `npm run golden`, `npm run build`, `E2E_PORT=<свободный порт> npm run e2e -- --workers=1`. Порт 5173 или 5199 может быть занят чужим dev-сервером; бери свободный, иначе тест проверит чужой код.
- Сообщения коммитов на английском, маленькие коммиты. В PR приложи скриншоты до и после для каждого размера.
- Сначала смотри скриншотами, потом правь CSS. Не делай слепые правки: правила в `responsive.css` перебивают друг друга по специфичности и порядку (`index.css` подключает `responsive.css` раньше `hud-theme.css` и `kid-theme.css`, поэтому для перебивания нужен селектор вида `.game .hud-panel.crew`).
